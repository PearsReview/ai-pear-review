# Review a pull request

Pull requests are reviewed with GitHub's **GitHub Pull Requests** extension, and
Pear Review adds its walkthrough, explanations and chat on top. That extension
is optional: **Review Pull Request…** offers to install it if it's missing.

1. **Review Pull Request…** opens GitHub's Pull Requests view. Sign in to GitHub
   there if it asks.
2. Right-click the pull request and choose **Checkout in Worktree**. That keeps
   your own checkout and uncommitted changes as they are; put the worktree
   beside your repository, not inside it. (A plain **Checkout** switches your
   branch instead.)
3. In the worktree's window, the Changes view lists the PR's changes against the
   point where it branched, as GitHub's **Files changed** shows them.
4. Ask about any change, by text, voice or selected lines, in Pear's diff or in
   GitHub's. ✨ in an editor's title bar explains the change the cursor is in.
5. Comment, suggest changes, mark files Viewed and submit the review with
   GitHub's extension: those go to the pull request. Pear's own comments,
   reviewed marks, Act Now and plans are off for a pull request.
