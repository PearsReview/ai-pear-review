# Open your changes

Open a git repository with uncommitted changes, then the **Pear Review** view
in the activity bar.

The **Changes** tree lists every changed file and its hunks. Click a hunk to
open it as a diff (HEAD ↔ your working file) with its lines highlighted. The
chat opens beside other chat extensions, in the secondary side bar.

With several repositories open, **Switch Repository** on the Changes view picks
the one to review; each keeps its own review.
