# Act Now

For a small change you'd rather see made now: press **Act Now** by the message
box, then say or type what to change. Your coding agent works in a copy of the
repository and proposes the change as a diff.

**Apply** writes it, **Refine** asks for changes to it, **Discard** drops it.
Nothing touches your files until you apply.

Act Now and Look deeper need a coding agent (Cline), chosen in the chat's ⚙.
