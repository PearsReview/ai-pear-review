# Start the review

**Start Review** (▶ on the Changes view) turns on the review proper: reviewed
marks, comments and the summary at the end.

Use ↑ / ↓ on the Changes view to move between changes, and ✓ to mark the one on
screen reviewed. Press ✨ in the chat to have the reviewer explain a change; to
explain every change as you reach it, choose **Explain changes: Automatically**
in the chat's ⚙.
