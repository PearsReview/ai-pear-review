# Ask about it

Type in the chat to ask about the change on screen. Select lines in the diff
first to ask about just those; the chat shows what goes with the question.

Press **Ctrl+Alt+Space** (**Cmd+Alt+Space** on macOS) to start speaking, and
again to send. 🔊 reads a reply aloud. **Look deeper** has your coding agent
read the repository for a more thorough answer.

Right-click any file and choose **Ask Pear About This File** to ask about code
that hasn't changed. On a markdown file, **Read Aloud** reads it to you.
